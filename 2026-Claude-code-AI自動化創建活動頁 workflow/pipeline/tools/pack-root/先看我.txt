Campaign Studio 單機版 —— 先看我
======================================

這是什麼
--------
一個在你自己電腦上做活動頁的工具。
不用登入任何帳號、不用另外安裝程式（需要的東西都在這個資料夾裡）。
只需要這台電腦有 Chrome，做頁的時候要能上網（它會去 Yahoo 購物抓商品資料和價格）。


第一次用：三步
--------------
1. 把下載的壓縮檔解開，會得到一個叫「CampaignStudio」的資料夾。放哪裡都可以，之後不要搬、不要改名。

2. 打開資料夾，對「安裝.command」按右鍵 → 選「打開」。
   如果電腦跳出「無法打開，因為它來自未識別的開發者」：
   → 打開「系統設定」→「隱私權與安全性」→ 往下捲，會看到「安裝.command 已被封鎖」→ 按「仍要打開」→ 再按一次「打開」。
   這只會發生在第一次。

3. 安裝會自己跑完，逐項告訴你「✓ 好了」、「⚠ 先提醒你一件事」或「✗ 哪裡不行、怎麼辦」。⚠ 不會擋安裝（例如這台現在連不到 Yahoo 購物，會先講、等網路好再開工具）。跑完會自動打開瀏覽器，看到工具的首頁就成功了。


之後每天
--------
雙擊「啟動 Campaign Studio.command」。
瀏覽器會自己打開 http://localhost:8787 —— 這個網址只有你這台電腦看得到，別人連不進來。
用完直接關掉那個黑色視窗就好。


你做的活動存在哪裡
------------------
在你的家目錄底下的「CampaignStudio」資料夾（Finder → 前往 → 個人專屬）。
換電腦或重灌前，把這個資料夾整個複製走就帶得走。


做好一頁之後怎麼交出去
----------------------
在工具裡按「製作 AEM 網頁檔」，會下載一個 HTML 檔。
把這個檔交給負責上傳官網系統（AEM）的人。
（上傳到 AEM 的步驟正在跟工程師確認中，這一版先做頁、下載；上傳方式確定後會另外通知。）


三件不要做
----------
・不要改這個資料夾裡任何資料夾的名字（程式認名字）。
・不要把裡面的東西搬到別處。
・不要同時開兩份工具。


遇到問題
--------
把畫面截圖（右上角有版本號，要一起拍到）傳給 Tofu。
如果「安裝.command」怎麼點都打不開：打開「終端機」，把資料夾裡的「install.sh」拖進終端機視窗，按 Enter，效果一樣。
